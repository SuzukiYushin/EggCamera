# 手動でシャットダウン → 起動 → ネットワーク変更 したときに人がやること

作成 2026-07-24 ／ **Claude Code なしで、人だけで実行できるように書いています**

実例: 2026-07-21 18:05 に手動シャットダウン → 07-24 23:11 に手動起動（約3日停止）。
このとき **サーバもネットワークも全部正常なのに、店頭のiPad画面だけが真っ白のまま**になりました。
自動では直りません。以下の手順で必ず直せます。

---

## ■ いちばん大事なこと（これだけは覚える）

> **Mac mini を再起動したら、iPadの画面は必ず一度死にます。**
> サーバが正常でも、iPadは古い画面を掴んだままになります。放っておいても直りません。
> **起動後は必ず iPadの画面を目で見て、くまの絵と「はじめる」が出ているか確認してください。**

---

## ■ A. 電源を落とす前にやること

### 1. お客様がいる時間帯なら、メンテナンスモードにする

ターミナルにこれをコピペ（合言葉は自動で読み込まれるので、そのまま貼るだけ）:

```sh
cd ~/EggCamera/EggCameraNode
curl -s -X POST -H "X-Admin-Token: $(grep -E '^ADMIN_TOKEN=' .env | cut -d= -f2)" \
  http://127.0.0.1:3001/api/admin/maintenance/start; echo
```

`{"maintenance":true...}` と出れば成功です。**解除は最後の `start` を `stop` に変えるだけ。**
今どちらの状態かを見るには:

```sh
cd ~/EggCamera/EggCameraNode
curl -s -H "X-Admin-Token: $(grep -E '^ADMIN_TOKEN=' .env | cut -d= -f2)" \
  http://127.0.0.1:3001/api/admin/maintenance; echo
```

### 2. 撮影が途中のお客様がいないことを確認する

iPadの画面を見て、誰も操作していないことを確認します。

### 3. 「今から止めます」の記録を残す（監視の誤検知を防ぐ）

ターミナルに以下をコピペ:

```sh
curl -s -X POST http://127.0.0.1:3000/api/test-report \
  -H 'Content-Type: application/json' \
  --data '{"level":"info","text":"DEPLOY-MARKER(manual): Mac手動シャットダウン。撮影断は本作業由来。"}'
```

### 4. Mac mini を通常どおりシャットダウン

アップルメニュー →「システム終了」。

> **注意**: 止めている間は、自動テストも自動監視も**一切動きません**。
> 3日止めれば3日分の記録が空白になります。長く止めるときは、それを承知の上で。

---

## ■ B. 電源を入れたあとにやること（3ステップだけ）

### ステップ1. Mac mini の電源を入れて、2〜3分待つ

常駐プログラムが自動で立ち上がるまで待ちます。

### ステップ2. 点検コマンドを1つ実行する

ターミナル（アプリケーション → ユーティリティ → ターミナル）を開いて、これをコピペ:

```sh
~/EggCamera/ops/after-boot-check.sh
```

**日本語で結果が出ます。**

- `結果: 問題なし ✅` → ステップ3へ
- `結果: 要対応が N 件 ❌` → 画面に出ている ❌ の行に、やるべきことが書いてあります。上から順に対処し、もう一度このコマンドを実行してください

### ステップ3. ★ iPadの画面を目で見る（これが最重要）

iPadに **くまの絵と「はじめる」ボタン** が出ていればOKです。

**真っ白・エラー・古い画面のままなら**、ターミナルにこれをコピペ:

```sh
~/EggCamera/ops/after-boot-check.sh --fix-kiosk
```

これでiPadのSafariが強制的に読み直されます。**それでも直らなければ、iPadの画面を指でタップして、
Safariの再読み込みボタン（アドレスバーの右にある ↻）を押してください。** これで必ず直ります。

---

## ■ C. ネットワーク（ルータ・Wi-Fi）を変えたとき

ネットワークを変えると、**Mac の住所（IPアドレス）が変わることがあります**。
iPadは「決まった住所」を見に行くので、住所が変わると画面が出なくなります。

### 1. まず点検コマンドを実行

```sh
~/EggCamera/ops/after-boot-check.sh
```

【1】の欄に **`❌ 不一致！`** と出たら、住所が変わっています。次へ進んでください。
出なければ、住所は変わっていないので何もしなくて大丈夫です。

### 2. 新しい住所に書き換える

点検コマンドが表示した「実際は 192.168.x.x」の数字を控えて、以下をコピペします。
**`192.168.10.999` の部分だけを、控えた数字に置き換えてください。**

```sh
cd ~/EggCamera
NEW_IP=192.168.10.999      # ← ここを実際の数字に置き換える
OLD_IP=$(grep -oE '192\.168\.[0-9]+\.[0-9]+' ops/ipad/ipad-wifi-reboot.sh | head -1)
grep -rl "$OLD_IP" ops/ EggCameraNode/tools/ipad-test.js | xargs sed -i '' "s/${OLD_IP}/${NEW_IP}/g"
echo "書き換え完了: $OLD_IP → $NEW_IP"
```

**iPad の住所も変わります。** 新しい住所は次のコマンドで分かります（`ip_address:` の
`192.168.x.x` の行）:

```sh
dscacheutil -q host -a name EggCameranoiPad.local
```

分かったら、Mac側と同じ要領で iPad の住所も置き換えます:

```sh
cd ~/EggCamera
NEW_IPAD_IP=192.168.10.999      # ← 上で調べた iPad の数字に置き換える
OLD_IPAD_IP=$(grep -oE '192\.168\.[0-9]+\.[0-9]+' ops/ipad/wda-forwarder.js | head -1)
grep -rl "$OLD_IPAD_IP" ops/ | xargs sed -i '' "s/${OLD_IPAD_IP}/${NEW_IPAD_IP}/g"
echo "書き換え完了: $OLD_IPAD_IP → $NEW_IPAD_IP"
```

### 3. ★ iPadのホーム画面アイコンを作り直す（IPが変わったら必ず必要）

**これを飛ばすと、iPadの画面は絶対に直りません。**

お客様が見るキオスク画面は、iPadのホーム画面にある「Egg Camera」アイコン
（＝Webアプリ／WebClip）から開いています。**このアイコンには古い住所が焼き付いていて、
あとから変更できません。** 住所が変わったら、必ず作り直してください。

iPadを手で操作します（所要1分）:

1. iPadでSafariを開き、アドレスバーに新しい住所 `192.168.11.106:3000` を入れて開く
2. くまの絵と「はじめる」が出ることを確認
3. 右上の **共有ボタン**（□に↑）をタップ
4. 下の方の **「表示を増やす」**（∨）をタップ → **「ホーム画面に追加」** をタップ
5. **「Webアプリとして開く」がON（緑）** になっていることを確認 ← これがOFFだとSafariの
   アドレスバーが出てしまい、キオスクとして使えません
6. 右上の **「追加」** をタップ
7. ホーム画面に増えた「Egg Camera」アイコンをタップして開く。**アドレスバーが無い状態**で
   くまの絵が出れば成功
8. 古いアイコンが残っていたら、長押し →「ブックマークを削除」で消す

### 4. もう一度点検して、全部 ✅ になるか確認

```sh
~/EggCamera/ops/after-boot-check.sh
```

### ★ 二度と起きないようにするには（おすすめ）

ルータの設定画面で、**Mac mini の有線に「192.168.11.106」を固定で割り当てる**（DHCP固定割当）。
こうすればネットワーク機器を替えても住所が動かず、上の書き換え作業そのものが不要になります。
iPad（192.168.11.104）も同じく固定にしておくと安定します。

> **2026-08-04 の実例**: ネットワークを 192.168.10.x → 192.168.11.x に変更。
> Mac=192.168.11.106 / iPad=192.168.11.104 になり、上の 2・3 をすべて実施して復旧しました。
> このとき **有線の差し口も USBアダプタ(en8) から Mac本体のLANポート(en0) に変わっています**。
> 点検コマンドは自動でどちらか使われている方を見るように直してあるので、気にしなくて大丈夫です。

| # | やること | 効果 |
|---|---|---|
| 1 | `~/EggCamera/ops/after-boot-check.sh --fix-kiosk` | ほとんどはこれで直る |
| 2 | iPadを指でタップ → Safariの再読み込み ↻ を押す | 確実。1が効かないときはこれ |

> キオスクは「この画面が開きっぱなし」で成り立っています。

## ■ E. 困ったとき早見表

| 症状 | 原因として多いもの | やること |
|---|---|---|
| iPad画面が真っ白 | Macを再起動した／画面部品の読み込み失敗 | D-1 → D-2 |
| iPad画面が「サーバに接続できません」 | ネットワークが変わって住所がズレた | C を最初から |
| iPadが反応しない・暗い | 電源が落ちた／電池切れ | 充電ケーブルを挿し、画面を長押しで起動 |
| 撮影ボタンを押しても撮れない | iPhone（カメラ）側の問題 | 点検コマンドの【2】を確認。iPhoneのUSBを挿し直す |
| 点検コマンドで「常駐◯◯が起動していない」 | 起動に失敗した | 表示されたコマンドをコピペ、または Mac を再起動 |
| 何をどうしても直らない | — | Mac mini を再起動 → B の手順をやり直す |

## ■ F. なぜこうなるのか（知っておくと安心）

- **Mac は住所を複数持ちます。** 現在の本番用は有線 `en0`（Mac本体のLANポート）＝`192.168.11.106`。
  以前は USB-Ethernetアダプタ（en8）を使っていたので、**どちらが使われているかは点検コマンドの
  【1】の表示を見てください**（自動で判別します）。
  Wi-Fi（en1）は再起動のたびに数字が変わります（実際に .113 → .108 と変わりました）。
  **iPadに教える住所は必ず有線側**です。Wi-Fi側の数字を使うと、次の再起動で必ず壊れます。

- **ホーム画面アイコン（Webアプリ）には住所が焼き付いています。** これが
  「サーバもネットワークも正常なのにiPad画面だけ出ない」の正体です。IPが変わったら
  **C-3 のアイコン作り直しが必須**で、`--fix-kiosk` では直せません。

- **iPadの画面は自動で復旧しません。** Macを再起動すると、iPadが開いていたページは
  中身が消えてエラー表示のまま固まります。iPad自身は「読み直そう」とはしません。

- **「Safariを起動する」だけでは直りません。** すでにSafariが動いていると、
  画面を前に出すだけで読み直してくれないためです。だから `--fix-kiosk` は
  **一度Safariを終了してから開き直す**という手順になっています。

- **自動の見張り役も、この故障だけは見つけられません。** サーバの見張りは
  「サーバが動いているか」しか見ていないので、iPadの画面が死んでいても気づきません。
  **だから最後に人が目で見る手順が必要です。**

## ■ 付録: よく使うアドレス・コマンド

| 用途 | コマンド／アドレス |
|---|---|
| 起動後の点検 | `~/EggCamera/ops/after-boot-check.sh` |
| iPad画面の強制読み直し | `~/EggCamera/ops/after-boot-check.sh --fix-kiosk` |
| キオスク画面（お客様が見る画面） | `http://192.168.11.106:3000/` |
| 撮影が通るかの通しテスト | `cd ~/EggCamera/EggCameraNode && node tools/prod-e2e.js --cycles 1` |

**管理画面を開く**（合言葉つきのアドレスを自動で組み立てて開きます）:

```sh
open "http://127.0.0.1:3001/admin/?token=$(grep -E '^ADMIN_TOKEN=' ~/EggCamera/EggCameraNode/.env | cut -d= -f2)"
```

> 管理画面は合言葉（トークン）が必要です。上のコマンドは `.env` から自動で読み取るので、
> 合言葉を覚えたり打ち込んだりする必要はありません。**このアドレスは他人に共有しないでください。**

**メンテナンスの開始／終了／確認**:

```sh
cd ~/EggCamera/EggCameraNode
T=$(grep -E '^ADMIN_TOKEN=' .env | cut -d= -f2)
curl -s -X POST -H "X-Admin-Token: $T" http://127.0.0.1:3001/api/admin/maintenance/start; echo  # 開始
curl -s -X POST -H "X-Admin-Token: $T" http://127.0.0.1:3001/api/admin/maintenance/stop;  echo  # 終了
curl -s        -H "X-Admin-Token: $T" http://127.0.0.1:3001/api/admin/maintenance;        echo  # 確認
```
