## 2. iPad テスト再開不可の真因と恒久対策（tunneld 常駐化）
**真因**: 無線(WiFi)接続の iPad は usbmux に居らず、Appium は RemoteXPC トンネル（`pymobiledevice3 remote tunneld` のレジストリ :49151）経由でしかデバイスを発見できない。Mac 再起動後に tunneld が未起動だったため `Tunnel registry port not found` → usbmux フォールバック → USB の iPhone のみ → iPad が `Unknown device`。root 必須・自動起動の launchd 常駐が無い ops gap。

**恒久対策（実装）**: iPhone の `com.eggcamera.iproxy` に相当する iPad 版 root 常駐サービスを追加。
- `ops/launchd/com.eggcamera.tunneld.plist` — root LaunchDaemon（RunAtLoad + KeepAlive）。
- `ops/ipad/tunneld-daemon.sh` — `pymobiledevice3 remote tunneld` 常駐ラッパー。
- `ops/ipad/install-tunneld-daemon.sh` — 冪等インストーラ（`sudo` で1回実行。:49151 応答と iPad トンネル確立を自動検証）。

**導入結果**: `sudo install-tunneld-daemon.sh` 実行済 → tunneld 稼働（pid、:49151 応答）。iPhone のトンネルは自動確立。**iPad は「信頼(Trust)」ペアリング承認待ちで未確立**（`Waiting user pairing consent`）。iOS17+ の物理タップが必須で、本日は iPad に触れないため保留。一度承認すれば永続化し、以後の再起動は自動確立の見込み。

## 2′. 【重要訂正】iPadテスト再開の真因と正解（上の tunneld 説は誤り）
深掘りの結果、§2 の「pymobiledevice3 `remote tunneld` 常駐」は**誤りと判明**。Appium(xcuitest)は独自の `appium-ios-remotexpc` トンネルしか見ず、独自 tunneld(:49151) は API 非互換で `Tunnel registry port not found` のまま無視される。

**真の原因(2層)**:
1. Mac再起動後、**iPadが usbmux から落ちる**（CoreDeviceでは paired/connected なのに `pymobiledevice3 usbmux list`/`idevice_id -l` に iPhone のみ）。→ **iPad の USB-C 抜き差し**で復帰（`TrustedHostAttached: true` で信頼ダイアログ不要）。「信頼ボタンが出ない」の正体はこれ＝信頼問題ではなく usbmux 列挙の問題。
2. Appium のデバイス発見に必要な公式トンネルレジストリが未起動。ポートは `@appium/strongbox`(container `appium-xcuitest-driver`, 既定42314, 保存先 `~/Library/Application Support/appium-xcuitest-driver-nodejs/strongbox/`)から読む。書くのは **`sudo appium driver run xcuitest tunnel-creation`** のみ。

**正解(検証済)**: ①iPadをusbmuxに出す（必要ならUSB-C抜き差し）→ ②`sudo appium driver run xcuitest tunnel-creation` を常駐 → ipad-test.js のセッション作成成功（`セッション: 0e02...` 確認）。

**恒久化(本日実装)**: 公式コマンドを root LaunchDaemon 化。誤った `com.eggcamera.tunneld` 一式は撤去。
- `ops/launchd/com.eggcamera.appium-tunnel.plist`(RunAtLoad+KeepAlive)
- `ops/ipad/appium-tunnel-daemon.sh`（**HOME=/Users/eggcamera 必須**＝strongbox/~/.appium をユーザ側に。root の /var/root だと Appium が読めない）
- `ops/ipad/install-appium-tunnel-daemon.sh`（旧tunneld撤去＋新daemon導入＋検証）。導入: `sudo .../install-appium-tunnel-daemon.sh`（事前に手動foregroundの tunnel-creation は Ctrl-C）。
- 撤去: `ops/ipad/tunneld-daemon.sh` / `install-tunneld-daemon.sh` / `ops/launchd/com.eggcamera.tunneld.plist`。
