# EggCamera 長期運用テスト用 Chrome 拡張

EggCamera のユーザーUI（`http://192.168.10.104:3000/` または `http://localhost:3000/`）を
自動操作して、長期運用テストを行うための拡張機能です。

## 動作内容（1サイクル）

1. スタート → はじめる
2. 名前入力 — ランダムな名前を入力（30%の確率でスキップ）
3. 生年月日 — ピッカーをランダムに選択（25%の確率でスキップ）
4. 撮影 — シャッターを押して3枚撮影（実機のiPhoneカメラが動きます）
5. 写真選択 — ランダムに1枚選択（15%の確率で一度「撮りなおす」で戻る）
6. ファイナルプレビュー → 保存
7. アップロード完了を待ち、QR画面で **downloadUrl を実際にfetchしてDL検証**
8. QR画面で指定秒数（デフォルト60秒）待機 → 最初に戻る → 次のサイクルへ

- 撮影エラー／アップロードエラーが出たら自動でリトライし、エラー数をカウント
- 同じ画面で150秒停滞したらエラー扱いでページをリロードして継続

## インストール

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」→ この `EggCameraTestExt` フォルダを選択

## 使い方

1. `http://192.168.10.104:3000/`（または localhost:3000）を開く
2. ツールバーの拡張アイコンをクリックしてポップアップを開く
3. QR画面の待機秒数を設定（デフォルト60秒）
4. 「開始」をクリック → 自動でサイクルが回り始める
5. ポップアップでサイクル数 / DL成功 / DL失敗 / エラー数とログを確認
6. 「停止」でいつでも止められる

ログはサーバ側でも `data/logs/server-YYYYMMDD.log` と
管理画面（`http://192.168.10.104:3000/admin` → ログタブ）で監視できます。

## 注意

- 撮影のたびに **実機のiPhoneが実際にシャッターを切ります**
- R2へのアップロードも実際に行われます（24時間保持 → 3時間ごとに自動削除）
- バグを見つけたら: ログを確認 → 修正 → `npm run build`（UserUI）→ サーバ再起動 → テスト再開
